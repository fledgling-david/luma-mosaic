# Three-direction system

Use this reference whenever the user has not selected a single mode. The three outputs should share the same identity anchors but differ in scene logic, color behavior, and composition—not merely in filters.

## 01 Source Match / 原图跟色

Purpose: create the version that feels most faithful to the photographs.

- Build the palette from the source's dominant and accent colors.
- Retain the observed time of day, light temperature, materials, and emotional tone.
- Prefer believable cleanup, reframing, and spatial unification over invented symbolism.
- New elements may fill gaps but should plausibly belong to the photographed world.

Success test: someone familiar with the original photos would describe the wallpaper as a polished expression of the same moment.

## 02 Intelligent Extension / 智能延展

Purpose: expand visual evidence into a new, coherent world.

- Identify one or two source cues with transformation potential: blanket folds can become hills; window light can become dawn; water reflections can become glass architecture.
- Preserve the source palette as an anchor, then add a controlled secondary palette.
- Make the extension semantically connected to the subject. Avoid generic fantasy scenery with no link to the photos.
- Use a noticeably different layout from Source Match.

Success test: the invented scene feels surprising but inevitable once its link to the source is explained.

## 03 Bold Reimagination / 大胆创新

Purpose: reveal a fresh interpretation while preserving identity.

- Select an art direction from the subject's character, shape language, era, movement, or story—not from a fixed preset.
- Change at least three of these: palette family, setting, lighting model, spatial structure, material language, or medium.
- Possible directions include editorial surrealism, ink-and-mineral landscape, luminous paper theatre, retro scientific plate, quiet brutalist architecture, maximal botanical opera, analogue film dream, or graphic folk art.
- Avoid repeating fashionable defaults such as neon cyberpunk, pink-purple galaxies, moons, or floating clouds unless the source genuinely supports them or the user requests them.
- Keep identity anchors realistic enough that the subject remains unmistakable.

Success test: it is the most adventurous version, but not a random style transfer.

## Mode overrides

If the user explicitly requests one direction, generate only that direction unless they also request alternatives. If they name a visual style, apply it within the selected mode rather than replacing the mode's identity and evidence rules.
